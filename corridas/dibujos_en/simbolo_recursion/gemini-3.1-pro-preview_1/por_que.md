I drew a fractal tree enclosed by continuous cyclic arrows, set against a dark-mode code editor background. I chose the fractal tree because it universally visualizes recursion: a main problem branching into identical, smaller sub-problems. The cyclical arrows emphasize self-referential function calls, and the editor window grounds the symbol in a programming context.

I initially considered the Droste effect (a picture within a picture), but discarded it because rendering clear, deeply nested scenes in raw SVG without external images is highly complex and risks visual clutter. I also considered Russian nesting dolls, but realized they could easily be misinterpreted as a symbol for data encapsulation, nested loops, or multidimensional arrays rather than a recursive algorithmic strategy. The fractal tree is the most unambiguous, elegant visual shorthand to instruct another AI to use recursion.
