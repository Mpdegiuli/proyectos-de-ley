I drew a “recursion” cue: nested rounded squares suggest a problem containing smaller versions of itself; diagonal arrows point inward to show reducing the problem step by step; the central dot with a check mark represents the base case; the large spiral arrow shows repeated self-calls unwinding toward termination. The side braces evoke code structure without using actual text, hinting that this is a programming strategy.

I considered drawing a tree, because recursive algorithms often branch, but it might suggest only tree traversal or divide-and-conquer. I considered mirrors facing each other, but that could imply infinity without termination. I also considered fractals like a Sierpinski triangle, but they might be read as geometry rather than an instruction. I chose nested boxes plus a spiral and base-case mark because it communicates “call yourself on smaller inputs until a stopping condition.”
