I drew nested, self-similar rectangles shrinking toward a red dot at the center. The frames repeat the same shape at smaller scales—recursion's core idea—while the red circle marks the base case where descent stops. Blue solid arrows point inward (successive recursive calls going deeper), and green dashed arrows point outward with growing size (returns unwinding back up the stack). A loop arrow exits the outer frame and curves back into itself, depicting a function calling itself. Together these encode call → deeper call → base case → return.

I considered a spiral (self-similar but reads as "iteration" or decoration), a fractal tree or Sierpinski triangle (evokes recursion but might suggest "draw fractals" rather than "use a recursive strategy"), mirrors reflecting mirrors (hard to render clearly in SVG), and matryoshka dolls (culturally dependent, ambiguous). The nested-frames-with-call/return-arrows design most directly mirrors how recursion executes in code.
