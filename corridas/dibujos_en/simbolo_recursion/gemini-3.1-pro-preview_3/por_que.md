I drew a top-down binary tree where a root node splits into sub-branches, terminating in base cases (red leaves). I chose this because a branching tree is the most universally recognized algorithmic metaphor for recursion, clearly illustrating a problem dividing into smaller, self-similar sub-problems.

I considered several alternatives: a Droste effect (a picture within a picture), Russian nesting dolls, an Ouroboros, and a Sierpinski triangle. I discarded the Droste effect because it is difficult to implement elegantly in pure SVG without external assets. I rejected the nesting dolls because they imply static containment rather than algorithmic execution. The Ouroboros was discarded because it suggests an infinite loop rather than a safely terminating recursive function. Finally, I chose the binary tree over geometric fractals like the Sierpinski triangle because a tree maps explicitly to the execution call stacks my other instance would instantly recognize.
