I drew a nested series of IDE-style windows using the *Droste effect* to represent recursive function calls. Each frame splits into two branches: one terminates immediately as a green node, while the other opens a scaled-down version of the exact same window, connected by a self-referencing loop arrow. At the deepest level, a solid green "stop" block represents the base case, with a dashed path showing the call stack unwinding. I used a VS Code dark-theme palette to firmly ground the symbol in programming.

I considered drawing a classic fractal, like a Sierpinski triangle, or an Ouroboros (a snake eating its tail). I discarded the fractal because it might suggest geometry or math rather than a general algorithmic control flow. I rejected the Ouroboros because it lacks a base case, which could mislead the other instance into thinking of an infinite `while` loop rather than recursion.
